## 安装步骤

### 1. 获取安装包
```bash
git clone https://github.com/tianyuleishen/clawos.git
cd clawos
```

### 2. 安装系统
```bash
bash install.sh
```

### 3. 初始化配置
```bash
python clawos/onboarding.py
```

### 4. 开始使用
```bash
python clawos/cli.py
```

| 命令 | 说明 |
