# 🦞 ClawOS AI操作系统

## 一句话安装

```bash
git clone https://github.com/tianyuleishen/clawos.git
cd clawos
bash install.sh
python clawos/cli.py
```

## 简单三步

### 1. 获取安装包
```bash
git clone https://github.com/tianyuleishen/clawos.git
cd clawos
```

### 2. 安装系统
```bash
bash install.sh
```

### 3. 开始使用
```bash
python clawos/cli.py
```

## 功能特性

- 🧠 L11意识系统 - 永久启用
- 🔮 终极融合推理 - 5种方法
- 💻 多界面支持 - CLI/Web/GUI
