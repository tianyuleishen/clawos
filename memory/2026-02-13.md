### 4. Sample Size Requirements

**To achieve <3% error margin**:
```
Formula: n = (z² × p × (1-p)) / e²
z = 1.96 (95% confidence)
p ≈ 0.8 (estimated accuracy)
e = 0.03 (target error)

Required: ~683 samples per dataset
```

## Key Insights

1. **Strengths**:
   - LogiQA: Excellent logical reasoning (95.60% ±2.54%)
   - RuleTaker: Outstanding 3-step chain reasoning (100%)
   - HLE: Far exceeds SOTA (<10% → 78.57%)

2. **Areas for Improvement**:

3. **Methodology**:
   - Bootstrap confidence intervals
