### 2. IM Integration - NEW!

**支持平台**
| 平台 | CLI配置 | Python API |
|------|---------|------------|
| 飞书 | `configure feishu --app-id XXX --app-secret XXX` | `IMManager.configure("feishu", {...})` |
| 企业微信 | `configure wecom --corp-id XXX --app-secret XXX` | `IMManager.configure("wecom", {...})` |
| 钉钉 | `configure dingtalk --app-key XXX --app-secret XXX` | `IMManager.configure("dingtalk", {...})` |
| QQ | `configure qq --http-url http://localhost:5700` | `IMManager.configure("qq", {...})` |

**CLI命令**
```bash
# 配置
clawos im configure feishu --app-id XXX --app-secret XXX
clawos im configure wecom --corp-id XXX --app-secret XXX
clawos im configure dingtalk --app-key XXX --app-secret XXX
clawos im configure qq --http-url http://localhost:5700

# 状态
clawos im status

# 连接/断开
clawos im connect feishu
clawos im disconnect feishu

# 发送
clawos im send feishu USER_ID "Hello!"
clawos im send-all "Hello all!"
```

**Python API**
```python
from clawos.im import IMManager

manager = IMManager()
manager.configure("feishu", {
    "app_id": "xxx",
    "app_secret": "xxx"
})
await manager.connect("feishu")
await manager.send_message("feishu", "user_id", "Hello!")
```
