## 🚀 快速开始

### 环境要求

- Python 3.10+
- 2GB RAM（推荐4GB+）

### 使用方式

```python
from clawos import Core

# 初始化
core = Core()

# 深度推理
result = await core.analyze("如果A>B，B>C，那么A>C吗？")
print(result.result)

# 代码生成
code = await core.generate_code("python", "实现快速排序算法")
print(code)

# 知识查询
knowledge = await core.query("相对论是什么？")
print(knowledge)
```

### 运行测试

```bash
# 运行增强版统计测试
python3 -m clawos.core.reasoning.enhanced_statistical_benchmark

# 查看详细报告
cat BENCHMARK_REPORT.md

# 查看优化报告
cat OPTIMIZATION_REPORT.md
```
