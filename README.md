## 🚀 快速开始

```bash
# 安装
pip install clawos

# 对话模式
clawos chat

# 推理测试
clawos reason "什么是相对论？"

# 创造力查询
clawos reason "帮我生成一个新产品的创意"

# 沟通查询
clawos reason "如何进行有效谈判？"

# IM配置
clawos im configure feishu --app-id XXX --app-secret XXX
```
