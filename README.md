## 🚀 快速开始

### 环境要求

- Python 3.10+
- 2GB RAM（推荐4GB+）
- 稳定网络连接

### 安装部署

```bash
# 克隆项目
git clone https://github.com/your-org/intellicore.git
cd intellicore

# 安装依赖
pip install -r requirements.txt

# 配置环境
cp config.example.yaml config.yaml
# 编辑配置文件

# 启动服务
python main.py
```

### 使用方式

```python
from intellicore import Core

# 初始化
core = Core()

# 智能问答
response = core.ask("如何提升团队效率？")
print(response)

# 内容生成
content = core.generate("项目进展报告", {"project": "X", "progress": "80%"})
print(content)
```
