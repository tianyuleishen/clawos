---

## 安装方法

### 1. 安装Git (如果没有)

下载: https://git-scm.com/download/win

### 2. 打开命令提示符 (cmd)

按 Win+R，输入 cmd，回车

### 3. 执行以下命令

```bash
git clone https://github.com/tianyuleishen/clawos.git
cd clawos
pip install -e .
```

### 4. 验证安装

```bash
clawos --help
```

---

## 使用方法

```bash
clawos --help     # 查看帮助
clawos init       # 初始化配置
clawos cli        # 命令行交互
clawos web        # Web界面
```
