🦞 ClawOS Windows用户使用指南
================================================================================

问题：pip安装失败

原因：代码中有错误的依赖引用（intellicore包不存在）

解决方案：使用零依赖版本，直接运行！

================================================================================
使用方法（无需安装）
================================================================================

方法1：双击运行（最简单）
--------------------------------
1. 下载ZIP文件并解压
2. 找到文件：ZERO_DEPENDENCY_CLAWOS.py
3. 双击这个文件
4. 会弹出命令行窗口，直接使用！

方法2：命令行运行
--------------------------------
1. 打开命令提示符 (Win+R → 输入 cmd → 回车)
2. 进入解压后的文件夹
3. 输入：
   python ZERO_DEPENDENCY_CLAWOS.py
4. 直接使用！
