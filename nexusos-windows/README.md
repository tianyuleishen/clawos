# NexusOS Windows 完整版

## 简介

NexusOS Windows完整版是一个具备完整AI能力的桌面助手。

## 功能

### 核心功能
- 意图理解 - 理解用户想做什么
- 电脑控制 - 打开应用/文件/网页
- UI自动化 - 鼠标/键盘控制
- 语音合成 - 4种音色
- 日志系统 - 自动记录运行日志

### 界面
- 科技感UI
- 数据流动画
- 情感人脸

## 安装

```bash
python install.py
```

## 运行

```bash
python nexusos_gui_full.py
```

## 打包

```bash
python build.py
```

## 日志

位置: `~/.nexusos/logs/nexusos.log`
